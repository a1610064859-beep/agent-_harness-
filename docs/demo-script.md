# 演示脚本（不超过 5 分钟）

赛题要求演示覆盖：资料查询、补充保存、多轮检查、追问、更正、跨会话记忆、适用规则的选择，并展示实际保存的数据和运行记录。

## 准备（不计入时长）

```bat
scripts\reset.bat          :: 恢复官方初始数据，确保每次演示结果一致
scripts\start-web.bat      :: 浏览器打开 http://127.0.0.1:8765
```

- 页面左侧选择 **U001 · C001 甲企业**，点“开始新会话”。
- `.env` 中设置 `FH_TODAY=2026-10-26`，让“上个月”等说法的结果固定。
- 浏览器缩放到 90%，右侧面板保持在“当前数据”。

## 讲解要点（各一句话）

- **分工**：模型负责理解和决定下一步；金额、规则版本、权限、保存与回读都由程序完成。所以这些数字和版本可以核对，不依赖模型“记得对”。
- **设计选择**：修改必须附上本会话用户的原话，用途文本也要能在原话里找到。旧会话的草稿和根据项目名称猜出来的用途因此执行不了。
- **对比实验**：常规场景下，模型自己挑规则也能答对。但在“已停用版本写着最适用内容”这种冲突中，模型有一半概率按已停用规则作答，程序解析则 0 错（见 `docs/acceptance/report.md`）。
